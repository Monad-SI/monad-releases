# Monad releases

Public downloads for Monad. This repository holds release assets only; the source is private.

- CLI: `curl -fsSL https://github.com/Monad-SI/monad-releases/releases/latest/download/install.sh | bash`
- Desktop: download the installer for your OS from the [latest release](https://github.com/Monad-SI/monad-releases/releases/latest). Installed apps update themselves from this repository's latest release.
- Verify: every release carries `SHA256SUMS` and `SHA256SUMS.bundle`, a Sigstore signature made by the `Monad-SI/monad-one` release workflow.

Releases are published here by that workflow. Nothing in this repository is built here.
